# Research Problem

Current career guidance and job recommendation systems often focus on matching a candidate's existing skills and resume keywords with job requirements. However, they generally provide limited support for identifying the candidate's skill gaps, understanding the semantic relationships between skills, explaining why specific skills are missing, and generating personalized learning or career recommendations based on those gaps.

Road2Hire aims to address this problem by developing an intelligent career guidance system that extracts skills from resumes, semantically matches them with job requirements, identifies skill gaps, represents relationships between skills and careers using a knowledge graph, predicts suitable career paths, and provides explainable, personalized recommendations using Retrieval-Augmented Generation (RAG).

The research therefore focuses on how NLP, semantic skill matching, knowledge graphs, career prediction, explainable AI, and personalized RAG can be integrated to provide accurate, explainable, and personalized skill-gap and career guidance.
