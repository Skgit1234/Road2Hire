## Overview

This directory preserves the historical development documentation, working research notes, and interim phase reports produced during the incremental implementation of Milestones M1 through M4.5 of the Road2Hire AI/ML project.

These individual files have been systematically synthesized and consolidated into the seven primary, versioned documents located directly in the parent [`Docs/`](file:///c:/Users/Sarvesh%20S.%20Kundale/Road2Hire/Docs/) folder:

2. **[`02_AI_ML_Research_and_Taxonomy.md`](file:///c:/Users/Sarvesh%20S.%20Kundale/Road2Hire/Docs/02_AI_ML_Research_and_Taxonomy.md):** Research problem, literature review, methodology, ESCO/O*NET taxonomy, and annotation schemas.
3. **[`03_AI_ML_Algorithms_and_Methodology.md`](file:///c:/Users/Sarvesh%20S.%20Kundale/Road2Hire/Docs/03_AI_ML_Algorithms_and_Methodology.md):** Algorithmic implementations, mathematical formulations, Hungarian bipartite matching, and SHAP explainability.
4. **[`04_AI_ML_Model_Evaluation_and_Limitations.md`](file:///c:/Users/Sarvesh%20S.%20Kundale/Road2Hire/Docs/04_AI_ML_Model_Evaluation_and_Limitations.md):** Cross-validation metrics, external benchmarks, 12 scientific limitations, and ethical AI governance.
5. **[`05_AI_ML_Output_and_Integration_Contract.md`](file:///c:/Users/Sarvesh%20S.%20Kundale/Road2Hire/Docs/05_AI_ML_Output_and_Integration_Contract.md):** Public Python interface (`process_resume`), Draft-07 JSON Schemas, and FastAPI integration guide.
6. **[`06_AI_ML_Database_Storage_Specification.md`](file:///c:/Users/Sarvesh%20S.%20Kundale/Road2Hire/Docs/06_AI_ML_Database_Storage_Specification.md):** Hybrid persistence schema, Mermaid ERD, and column-by-column PostgreSQL data mapping.
7. **[`07_AI_ML_Final_Handover.md`](file:///c:/Users/Sarvesh%20S.%20Kundale/Road2Hire/Docs/07_AI_ML_Final_Handover.md):** Technical handover specification, operational boundaries, and integration checklists.
