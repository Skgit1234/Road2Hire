# Tests

This directory contains all testing resources for the Road2Hire project.

## Structure

- Backend/      → Backend API unit tests.
- Frontend/     → Frontend component and UI tests.
- AI/           → AI/ML model and NLP tests.
- Integration/  → End-to-end integration tests.
- Data/         → Sample resumes and mock datasets for testing.

> Note: During the project setup phase, these folders contain only `.gitkeep` files. Test files will be added during the development milestones.
